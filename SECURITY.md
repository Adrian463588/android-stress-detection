# Security policy

This repository is a thesis prototype, not a clinically validated product.
The linked Android downloads are internal debug previews unless a release is
explicitly identified otherwise.

Report a security issue privately to the repository owner. Do not include
credentials, participant data, or exploitable details in a public issue. Revoke
any credential that may have been exposed; deleting a later commit does not
remove it from Git history.

Before changing repository visibility, run the publication safety workflow and
the documented full-history checks. R8 is defense-in-depth and does not make a
distributed APK impossible to inspect.
